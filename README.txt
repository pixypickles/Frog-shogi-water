水中蛙将棋 Prototype v2.1.3

GitHub Pages向け：このフォルダの中身をリポジトリ直下へ置いてください。
index.html が水中蛙将棋の入口です。

v2.1.3 主な変更
- 全編横画面前提。将棋盤は縦方向を最大限使用し、マスと駒を横長化。
- 「格闘ゲームへ」を削除。「格闘操作練習」を追加。
- 天使軍＝プレイヤー、悪魔軍＝CPU。CPUが盤上の手を自動で指します。
- CPUが攻めて格闘になった場合、プレイヤーは防御側（HP33）を操作します。
- 格闘前に「攻撃側 ○○さん / 防御側 ○○さん」を将棋画面上に表示し、そのまま読み込み表示。
- 成りは「このまま成る / カワズさんで成る / 成らない」の3択。
- 行き場のない歩・香車・桂馬は成り必須。必須時は「成らない」を非表示。
- 通常成りは元キャラのまま。特殊成りは天使軍カワズさん（CPU悪魔軍はコカビエルさん）。
- 格闘終了後は将棋盤へ直帰。

格闘ルール
攻撃側 HP100 / 防御側 HP33
攻撃側が勝つ：捕獲して相手マスへ進む
防御側が勝つ：攻撃駒は移動前のマスに残る
